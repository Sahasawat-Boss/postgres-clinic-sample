# Feature Ideas 2026-11-11 #1

## ⚠️ ควรแก้ก่อนเพิ่มของใหม่

- **role ไม่ถูกใช้งานจริง** — มี `admin`/`staff` ใน `users` และ `SessionUser` แต่ไม่มี API ไหนเช็ค role (grep เจอแค่ใน login + Sidebar) → staff ลบผู้ป่วยได้ (`DELETE /api/patients/:id`) ซึ่งลบนัด/ประวัติตาม CASCADE ด้วย
  - แตะ: `src/lib/auth.ts` (เพิ่ม `requireRole`), `src/app/api/patients/[id]/route.ts`, ซ่อนปุ่มลบใน `src/app/(app)/patients/[id]/page.tsx` · **S**
- **รหัสผ่านเดโมอยู่ใน repo public** — `admin1234` อยู่ใน README และ `db/03_users.sql` และไม่มีหน้าเปลี่ยนรหัสผ่าน ถ้า deploy ขึ้นออนไลน์ ใครก็เข้าเป็น admin ได้
  - ทางแก้: หน้า "เปลี่ยนรหัสผ่าน" + ตั้งให้ deploy ใช้ seed แยก / หรือทำบัญชีเดโมเป็น read-only · **S–M**
- **login ไม่มี rate limit** — `POST /api/auth/login` ลองรหัสได้ไม่จำกัด (ยิ่งเสี่ยงคู่กับข้อบน)
  - แตะ: `src/app/api/auth/login/route.ts` (นับครั้งผิดต่อ email/IP ในตาราง หรือ in-memory สำหรับเดโม) · **S**
- **token เพิกถอนไม่ได้** — ตอนนี้ "จดจำฉันไว้" ทำให้ JWT อยู่ 30 วัน แต่ logout แค่ลบ cookie ฝั่งเครื่อง; ถ้าลบ user หรือเปลี่ยนรหัส token เดิมยังใช้ได้จนหมดอายุ
  - ทางแก้: เพิ่ม `users.token_version` ใส่ใน JWT แล้วเทียบตอน `requireAuth` (proxy เช็คแค่ลายเซ็นต่อได้) · **M**

## Quick win (< ครึ่งวัน)

- **รัน HN อัตโนมัติ** — ตอนนี้ต้องพิมพ์ HN เอง (`PatientForm.tsx:53` placeholder `HN000007`) เสี่ยงพิมพ์ผิด/ชน 409 บ่อย
  - ใช้ sequence ใน Postgres (`CREATE SEQUENCE hn_seq` + default `'HN' || lpad(nextval…)`) แล้วเอาช่อง HN ออกจากฟอร์มตอนสร้าง
  - แตะ: `db/04_hn_sequence.sql`, `prisma/schema.prisma` (db pull), `src/lib/validation.ts`, `src/components/PatientForm.tsx` · **S**
- **กันนัดชนกัน** — `POST /api/appointments` สร้างได้ทุกเวลา แพทย์คนเดียวโดนนัดเวลาเดียวกันซ้ำได้
  - เช็คนัด `scheduled` ของ `doctor_id` ช่วง ±30 นาทีก่อน create ตอบ 409 · ได้ฝึก query ช่วงเวลา
  - แตะ: `src/app/api/appointments/route.ts` · **S**
- **เลื่อนนัด (reschedule)** — `PATCH /api/appointments/:id` รับแค่ `status` (`appointmentStatusSchema`) ถ้าคนไข้ขอเลื่อนต้องยกเลิกแล้วสร้างใหม่ ประวัติเลยรก
  - แตะ: `src/lib/validation.ts`, `src/app/api/appointments/[id]/route.ts`, ปุ่ม "เลื่อน" ในหน้า appointments/patient · **S**

## Impact สูง

- **Pagination ฝั่ง server** — `GET /api/patients` และ `/api/appointments` ใช้ `findMany` ไม่มี `take/skip` (มีแค่ใน dashboard) คลินิกจริงมีคนไข้หลักพัน → โหลดทั้งตารางทุกครั้งที่พิมพ์ค้นหา
  - cursor/offset + `total` ใน response, ปุ่มหน้าถัดไปใน `src/app/(app)/patients/page.tsx` · **M**
- **หน้าจัดการแพทย์ + ผู้ใช้ (admin only)** — มีแค่ `GET /api/doctors` ไม่มี UI เพิ่ม/แก้แพทย์ และสร้างบัญชีเจ้าหน้าที่ต้องเขียน SQL + hash เอง
  - ต่อยอดจากข้อ role ด้านบน: `src/app/(app)/settings/`, `src/app/api/doctors/[id]`, `src/app/api/users` · **M**
- **Audit log ข้อมูลผู้ป่วย** — ข้อมูลการรักษาเป็นข้อมูลอ่อนไหว (PDPA) แต่ตอนนี้ไม่รู้ว่าใครแก้/ลบอะไรเมื่อไหร่ (`updated_at` บอกแค่เวลา)
  - ตาราง `audit_logs(user_id, action, entity, entity_id, diff, created_at)` เขียนใน PUT/DELETE/POST · โชว์ใน timeline หน้าผู้ป่วย · **M** — จุดขายดีสำหรับพอร์ต

## Nice to have

- **ใบเสร็จ/สรุปการรักษาพิมพ์ได้** — `visits` มี `fee`, `diagnosis`, `treatment` ครบแล้วแต่ไม่มีทางออกเอกสารให้คนไข้
  - หน้า `/visits/[id]/print` + `@media print` CSS · **S–M**
- **กราฟบนแดชบอร์ด** — `/api/dashboard` ส่งแค่ตัวเลขรวม เพิ่มรายได้/จำนวนเคสรายวัน 30 วันล่าสุด (`GROUP BY date_trunc`) — ได้ฝึก SQL aggregate ด้วย
  - แตะ: `src/app/api/dashboard/route.ts` (`$queryRaw`), `src/app/(app)/dashboard/page.tsx` + lib กราฟ (ยังไม่ได้ลง) · **M**
- **แก้ไขบันทึกการรักษา (visit)** — `/api/visits` มีแค่ `POST` บันทึกผิด (เช่น fee/diagnosis) แก้ไม่ได้เลย ต้องไปแก้ใน DB
  - `PUT /api/visits/[id]` + ฟอร์มแก้ในหน้าผู้ป่วย · ถ้าทำ audit log แล้วจะเห็นประวัติการแก้ด้วย · **S**
- **ปฏิทินนัดรายวัน/รายสัปดาห์ แยกตามแพทย์** — หน้า appointments ตอนนี้เป็นลิสต์ ดูยากว่าแพทย์คนไหนว่างช่วงไหน
  - ใช้ `idx_appointments_time` ที่มีอยู่แล้ว query ช่วงวัน + group ตาม `doctor_id` แสดงเป็น grid เวลา (เขียนเองด้วย Tailwind ได้ ไม่ต้องลง lib) · คู่กับข้อ "กันนัดชนกัน" · **M**
- **นัดที่เลยเวลาแล้วยัง `scheduled`** — ไม่มีอะไรเปลี่ยนสถานะนัดที่ผ่านไปแล้ว ตัวเลข "นัดที่รอ" บนแดชบอร์ดเลยบวม
  - แสดง badge "เลยเวลา" (`appointment_at < now() AND status = 'scheduled'`) + ปุ่ม mark `no_show` (ต้องเพิ่มค่าใน check constraint) · **S**
- **Export CSV** — รายชื่อผู้ป่วย / รายได้ตามช่วงวัน ให้คลินิกเอาไปทำบัญชีต่อใน Excel
  - `GET /api/patients/export`, `GET /api/visits/export?from=&to=` ตอบ `text/csv` (ใส่ BOM `﻿` ให้ Excel อ่านภาษาไทยถูก) · **S**
- **ค้นหาด้วยชื่อเต็ม** — search ใช้ `contains` แยก `first_name`/`last_name` (`src/app/api/patients/route.ts:16`) พิมพ์ "สมชาย ใจดี" จะไม่เจอ
  - split คำด้วยช่องว่างแล้ว `AND` ทุกคำ หรือใช้ `pg_trgm` + index ถ้าอยากฝึก Postgres ลึกขึ้น · **S**
- **Dark mode** — ใช้ Tailwind v4 `dark:` variant + toggle ใน `Sidebar.tsx` เก็บค่าใน cookie กันจอกระพริบตอนโหลด · **S**
